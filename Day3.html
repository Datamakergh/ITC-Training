|Semantic Segmentation
Semantic Segmentation

What Is Semantic Segmentation?

Semantic segmentation is a group of pixels that acts as a reference point for object detection and produces a mesh-like map for that object.

  • Annotators group the pixels by drawing over the image.
  • Every pixel of the object gets the object’s class, for example body.

Front mode and rear mode

|Semantic Segmentation
Other Tools

Front and Rear Mode

Front Mode Shift + F
  • If there is an existing shape, you draw on top of that shape.
Rear Mode Shift + R
  • If there is an existing shape, you draw behind that shape.
  • These modes apply to all the main tools. You can only use one at a time.
  • If no shape is drawn in that region yet, front or rear mode gives the same result.
  • You can leave it in rear mode, so that every new shape falls behind the others.

Understanding 3D and LiDAR Fundamentals

Introduction to three-dimensional space and the principles of LiDAR

|3D & LiDAR
3D Space

Introduction to Three-Dimensional Space

3D (three-dimensional): we normally talk about dimensions as measurements in a direction.

Real-world objects exist in 3D space, allowing deeper perception through height, width and depth.

|3D & LiDAR
Basics

Spatial Coordinates and Dimensions

Spatial coordinates use the X, Y and Z axes to locate points in 3D space.

X: Horizontal
The horizontal position (left or right).
Y: Vertical
The vertical position (up or down).
Z: Depth
The depth, or position along the third dimension.
|3D & LiDAR
Uses

Uses of Spatial Coordinates and Dimensions

Dimensions add depth to objects, enhancing realism.

Technology and Computing
Computer graphics, VR and simulation: realistic 3D environments, robotics and automation, VR / AR and GPS navigation.
Navigation and Mapping
Accurate navigation and mapping: find locations, plan routes and understand geographic relationships.
Autonomous Vehicles
Mapping, navigation and object detection; localisation, map creation, path planning and safe intersection management.
|3D & LiDAR
LiDAR

LiDAR Fundamentals

LiDAR (Light Detection and Ranging) is a remote sensing technology that uses laser pulses to measure distances to objects or surfaces.

  • It creates detailed 3D maps.
  • Used for mapping, navigation and urban planning.

|PCD Project
Introduction

Introduction to the PCD Project

PCD stands for Point Cloud Data: points that represent data picked up by a LiDAR signal.

|PCD Project
Purpose

Why Does This PCD Project Exist?

Object Detection and Recognition
Autonomous vehicles must detect pedestrians, vehicles, cyclists and obstacles.
Depth Perception
Knowing the distance to objects is crucial for braking, lane changes and avoiding collisions.
Environment Understanding
Road boundaries, lane markings, traffic signs and other infrastructure.
Safety and Reliability
Accurate labels reduce the risk of misinterpreting the surroundings.
